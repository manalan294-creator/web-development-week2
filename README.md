# Budget Tracker

This project is a simple budget tracking page built with HTML and CSS. It includes a form for entering expenses, a table showing recent spending, a budget guidance section, and a short educational video.

## Files

- index.html — Contains the page structure and all required HTML content.
- style.css — Styles the layout, table, form, buttons, and advanced CSS selectors.
- README.md — Explains the project and describes each section.

## What the page includes

### Expense table
The page contains a properly structured table with a header row and multiple sample expense entries. It uses the required table elements: `table`, `thead`, `tbody`, `tr`, `th`, and `td`.

### Add Expense form
The form includes labeled inputs for the expense name, amount, category, and date. The category field is a dropdown with five options: Food, Transport, Rent, Entertainment, and Other. All inputs have matching `id` attributes and the button is set to `type="button"` as required.

### Multimedia content
A small image is placed near the main page heading, and a YouTube video is embedded with the correct iframe attributes so it displays correctly in the browser.

### Interactive section
The page includes a collapsible `details` and `summary` section titled “How to use this tracker.” The expense rows also change background color on hover and the button uses a pointer cursor.

### Advanced CSS styling
The stylesheet uses several advanced selectors, including a descendant selector, a direct child selector, a pseudo-class for even rows, a negation selector, and a focus state for inputs. These rules help improve the overall layout and user experience.

## How to view
Open the `index.html` file in a browser to view the project.
